# Design System

## Status

Initial Modern Clean design-token system implemented.

## Purpose

Capture the design language, interface patterns, accessibility expectations, and component conventions for VERRUM.

## To Be Defined

## Implemented

- Semantic CSS tokens for background, surface, border, text, primary, and status colors
- Light and dark mode support
- Density support: comfortable, compact, dense
- App shell, sidebar, topbar, page shell
- Buttons, badges, metrics, tables, evidence and calculation panels

## Direction

The UI should remain calm, precise, operational, and information-first. Avoid generic dashboard clutter and decorative charts.

## Design Guidance Skill

The `design-taste-frontend` skill is installed under `.agents/skills/` for future design review and refinement passes.

## Notes

Design decisions should support the actual user workflows described in `docs/PRODUCT_SPEC.md`.
