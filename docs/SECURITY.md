# Security

## Status

Draft placeholder. Security requirements have not been defined yet.

## Purpose

Document security expectations, threat model, access controls, and data protection standards for VERRUM.

## Baseline Rules

- Do not commit secrets.
- Prefer least-privilege access.
- Validate all untrusted input.
- Log enough for operations without exposing sensitive data.
- Document security-sensitive decisions in `docs/DECISION_LOG.md`.
